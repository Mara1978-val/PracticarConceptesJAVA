    💻 Exercici Pràctic RA1 (2 punts)

    ☕ Repte: Declaració de variables i suma bàsica

    Valor: 2.0 punts
    Enunciat: Completa el programa Java següent per a que:
    • Declare dues variables enteres (int) amb valors a la teua elecció.
    • Les some guardant el resultat en una altra variable.
    • Mostre el resultat per pantalla amb System.out.println().
    • Incloga un comentari d'una sola línia amb // explicant què fa el programa.

    ℹ️ Aquest exercici no necessita dades d'entrada. L'execució mostra la sortida real del teu codi.

    Consola de Sortida Java
    💡 Solució de referència comentada: 
    public class Main {
    public static void main(String[] args) {
        // Comentari: Suma de dues variables enteres
        int a = 5;
        int b = 7;
        int suma = a + b;
        System.out.println("La suma és " + suma);
    }
}

    💻 Exercici Pràctic RA3 (2 punts)

    ☕ Repte: Classificació numèrica amb if / else if / else

    Valor: 2.0 punts
    Enunciat: Fes un programa que demane un número per teclat i mostre per pantalla si és:
    • "Positiu" (si és major que 0)
    • "Negatiu" (si és menor que 0)
    • "Zero" (si és igual a 0)

    ℹ️ Aquest exercici es prova automàticament amb tres valors: 15, -4 i 0.

    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Número: ");
        int num = sc.nextInt();

        if (num > 0) {
            System.out.println("Positiu");
        } else if (num < 0) {
            System.out.println("Negatiu");
        } else {
            System.out.println("Zero");
        }
    }
}

    💻 Exercici Pràctic RA5 (2 punts)

    ☕ Repte Bàsic: Entrada amb Scanner i Càlcul d'Edat

    Valor: 2.0 punts
    Enunciat: Fes un programa que demane per teclat el nom de l’usuari i la seua edat.
    Després, el programa ha de calcular l'any de naixement (suposant que estem en 2026) i mostrar el missatge exacte:
    "Hola <nom>, vas nàixer l’any <any>."
    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nom: ");
        String nom = sc.nextLine();

        System.out.print("Edat: ");
        int edat = sc.nextInt();

        int anyNaixement = 2026 - edat;

        System.out.println("Hola " + nom + ", vas nàixer l'any " + anyNaixement + ".");
    }
}

    💻 Exercici Pràctic RA6 (2 punts)

    ☕ Repte: Recorregut d'un vector i cerca de Màxim i Mínim

    Valor: 2.0 punts
    Enunciat: Fes un programa que:
    • Cree un vector d'enters de mida 5 (new int[5]).
    • Demane cada número per teclat amb un bucle for.
    • Calcule i mostre el valor màxim i el mínim trobats al vector.
    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int[] numeros = new int[5];

        for (int i = 0; i < 5; i++) {
            System.out.print("Número " + (i + 1) + ": ");
            numeros[i] = sc.nextInt();
        }

        int max = numeros[0];
        int min = numeros[0];

        for (int i = 1; i < 5; i++) {
            if (numeros[i] > max) {
                max = numeros[i];
            }
            if (numeros[i] < min) {
                min = numeros[i];
            }
        }

        System.out.println("Màxim: " + max);
        System.out.println("Mínim: " + min);
    }
}

    🟢 Nivell bàsic — Fitxa d'alumne amb mitjana i resultat

    Fitxa d'alumne amb mitjana i resultat

    Pràctica · 1.0 punt · RA1 + RA3 + RA5 + RA6
    Enunciat: Llegeix el nom, l'edat i 3 notes d'un alumne. Les notes ja es guarden en un vector amb un bucle for escrit. Has de completar: la suma de notes, el càlcul de la mitjana i un if / else que mostri Aprovat o Suspès. Finalment imprimeix la fitxa completa amb el nom, l'edat, la mitjana i el resultat.
    Consola de Sortida Java
    💡 Solució guiada completa: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Llegeix la fitxa d'un alumne i calcula la seua mitjana
        Scanner sc = new Scanner(System.in);

        System.out.print("Nom: ");
        String nom = sc.nextLine();
        System.out.print("Edat: ");
        int edat = sc.nextInt();

        int[] notes = new int[3];
        int suma = 0;

        for (int i = 0; i < 3; i++) {
            System.out.print("Nota " + (i + 1) + ": ");
            notes[i] = sc.nextInt();
            suma = suma + notes[i];
        }

        int mitjana = suma / 3;

        String resultat;
        if (mitjana >= 5) {
            resultat = "Aprovat";
        } else {
            resultat = "Suspés";
        }

        System.out.println("--- Fitxa de l'alumne ---");
        System.out.println(nom + " (" + edat + " anys)");
        System.out.println("Mitjana: " + mitjana);
        System.out.println("Resultat: " + resultat);
    }
}

    🟡 Nivell mitjà — Tiquet de compra amb descompte

    Tiquet de compra amb descompte

    Pràctica · 1.0 punt · RA1 + RA3 + RA5 + RA6
    Enunciat: Fes una aplicació de tiquet: llegeix el número de productes i els seus preus, guarda'ls en un vector, calcula el total, el preu màxim i quants productes superen 100. Si el total passa de 500, aplica un descompte del 10%. Mostra un tiquet formatat amb tots els conceptes. El vector i la lectura ja estan escrits; completeu el càlcul i les condicions.
    Consola de Sortida Java
    💡 Solució guiada completa: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Llegeix preus, calcula estadístiques i aplica descompte
        Scanner sc = new Scanner(System.in);

        System.out.print("Nombre de productes: ");
        int n = sc.nextInt();
        int[] preus = new int[n];
        int total = 0;
        int maxim = 0;
        int cars = 0;

        for (int i = 0; i < n; i++) {
            System.out.print("Preu " + (i + 1) + ": ");
            preus[i] = sc.nextInt();
            total = total + preus[i];
            if (preus[i] > maxim) {
                maxim = preus[i];
            }
        }

        for (int i = 0; i < n; i++) {
            if (preus[i] > 100) {
                cars++;
            }
        }

        int descompte = 0;
        if (total > 500) {
            descompte = total * 10 / 100;
        }

        int aPagar = total - descompte;

        System.out.println("===== TIQUET =====");
        System.out.println("Total: " + total);
        System.out.println("Preu maxim: " + maxim);
        System.out.println("Productes > 100: " + cars);
        System.out.println("Descompte: " + descompte);
        System.out.println("A pagar: " + aPagar);
    }
}

    🔴 Nivell avançat — Informe de qualitat de sensors

    Informe de qualitat de sensors

    Pràctica · 1.0 punt · RA1 + RA3 + RA5 + RA6
    Enunciat: Aplicació més completa per validar 6 lectures de sensors. La funció esValida(int) i l'estructura bàsica ja estan escrites. Has de completar: la funció de validació (valor entre 0 i 40), el recompte de lectures vàlides/invàlides, la suma i el màxim/mínim només de les vàlides, i un informe final amb la mitjana i el número de sensors òptims (≥ 25). Mostra també l'estat de cada sensor amb if / else.
    Consola de Sortida Java
    💡 Solució guiada completa: 
    import java.util.Scanner;

public class Main {
    public static boolean esValida(int valor) {
        return valor >= 0 && valor <= 40;
    }

    public static void main(String[] args) {
        // Validació i estadístiques de lectures de sensors
        Scanner sc = new Scanner(System.in);
        int[] sensors = new int[6];
        int valides = 0;
        int suma = 0;
        int maxim = 0;
        int minima = 9999;
        int optims = 0;

        for (int i = 0; i < 6; i++) {
            System.out.print("Sensor " + (i + 1) + ": ");
            sensors[i] = sc.nextInt();

            if (esValida(sensors[i])) {
                System.out.println("Sensor " + (i + 1) + ": Correcte");
                valides++;
                suma = suma + sensors[i];
                if (sensors[i] > maxim) { maxim = sensors[i]; }
                if (sensors[i] < minima) { minima = sensors[i]; }
                if (sensors[i] >= 25) { optims++; }
            } else {
                System.out.println("Sensor " + (i + 1) + ": Invalid");
            }
        }

        System.out.println("===== INFORME =====");
        System.out.println("Lectures valides: " + valides);
        if (valides > 0) {
            System.out.println("Mitjana: " + (suma / valides));
            System.out.println("Maxima: " + maxim);
            System.out.println("Minima: " + minima);
            System.out.println("Optims: " + optims);
        } else {
            System.out.println("Sense lectures valides");
        }
    }
}
