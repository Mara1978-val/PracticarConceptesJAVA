    💻 Exercici Pràctic RA1 (2 punts)

    ☕ Repte: Declaració de variables i suma bàsica

    Valor: 2.0 punts
    Enunciat: Completa el programa Java següent per a que:
    • Declare dues variables enteres (int) amb valors a la teua elecció.
    • Les some guardant el resultat en una altra variable.
    • Mostre el resultat per pantalla amb System.out.println().
    • Incloga un comentari d'una sola línia amb // explicant què fa el programa.

    ℹ️ Eixe exercici no necessita dades d'entrada. L'execució mostra la sortida real del teu codi.

    Consola de Sortida Java
    💡 Solució de referència comentada: 
    public class Main {
    public static void main(String[] args) {
        // Comentari: Suma de dues variables enteres
        int a = 5;
        int b = 7;
        int suma = a + b;
        System.out.println("La suma és " + suma);
    }
}

    💻 Exercici Pràctic RA3 (2 punts)

    ☕ Repte: Classificació numèrica amb if / else if / else

    Valor: 2.0 punts
    Enunciat: Fes un programa que demane un número per teclat i mostre per pantalla si és:
    • "Positiu" (si és major que 0)
    • "Negatiu" (si és menor que 0)
    • "Zero" (si és igual a 0)

    ℹ️ Eixe exercici es prova automàticament amb tres valors: 15, -4 i 0.

    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Número: ");
        int num = sc.nextInt();

        if (num > 0) {
            System.out.println("Positiu");
        } else if (num < 0) {
            System.out.println("Negatiu");
        } else {
            System.out.println("Zero");
        }
    }
}

    💻 Exercici Pràctic RA6 (2 punts)

    ☕ Repte: Recorregut d'un vector i cerca de Màxim i Mínim

    Valor: 2.0 punts
    Enunciat: Fes un programa que:
    • Cree un vector d'enters de mida 5 (new int[5]).
    • Demane cada número per teclat amb un bucle for.
    • Calcule i mostre el valor màxim i el mínim trobats al vector.
    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int[] numeros = new int[5];

        for (int i = 0; i < 5; i++) {
            System.out.print("Número " + (i + 1) + ": ");
            numeros[i] = sc.nextInt();
        }

        int max = numeros[0];
        int min = numeros[0];

        for (int i = 1; i < 5; i++) {
            if (numeros[i] > max) {
                max = numeros[i];
            }
            if (numeros[i] < min) {
                min = numeros[i];
            }
        }

        System.out.println("Màxim: " + max);
        System.out.println("Mínim: " + min);
    }
}

    int-basic-1 — Mitjana de notes

    Mitjana de notes

    Pràctica · 1.0 punt · RA1 + RA3 + RA5 + RA6
    Enunciat: Llegeix tres notes enteres, desa-les en un vector int[] anomenat notes i calcula la mitjana sencera amb un bucle for. Mostra «Mitjana: X» i «Resultat: Aprovat» si la mitjana és almenys 5, o «Resultat: Suspès» si no.
    Consola de Sortida Java
    💡 Solució guiada completa: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Llegim les notes i les desem en un vector int[]
        Scanner sc = new Scanner(System.in);
        int[] notes = new int[3];
        int suma = 0;
        String resultat = "";

        for (int i = 0; i < notes.length; i++) {
            notes[i] = sc.nextInt();
        }

        for (int i = 0; i < notes.length; i++) {
            suma = suma + notes[i];
        }
        int mitjana = suma / notes.length;

        if (mitjana >= 5) {
            resultat = "Aprovat";
        } else {
            resultat = "Suspès";
        }

        System.out.println("Mitjana: " + mitjana);
        System.out.println("Resultat: " + resultat);
    }
}
