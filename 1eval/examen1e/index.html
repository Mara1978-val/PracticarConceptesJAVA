    💻 Exercici Pràctic RA1 (2 punts)

    ☕ Repte: Declaració de variables i suma bàsica

    Valor: 2.0 punts
    Enunciat: Completa el programa Java següent per a que:
    • Declare dues variables enteres (int) amb valors a la teua elecció.
    • Les some guardant el resultat en una altra variable.
    • Mostre el resultat per pantalla amb System.out.println().
    • Incloga un comentari d'una sola línia amb // explicant què fa el programa.

    ℹ️ Aquest exercici no necessita dades d'entrada. L'execució mostra la sortida real del teu codi.

    Consola de Sortida Java
    💡 Solució de referència comentada: 
    public class Main {
    public static void main(String[] args) {
        // Comentari: Suma de dues variables enteres
        int a = 5;
        int b = 7;
        int suma = a + b;
        System.out.println("La suma és " + suma);
    }
}

    💻 Exercici Pràctic RA3 (2 punts)

    ☕ Repte: Classificació numèrica amb if / else if / else

    Valor: 2.0 punts
    Enunciat: Fes un programa que demane un número per teclat i mostre per pantalla si és:
    • "Positiu" (si és major que 0)
    • "Negatiu" (si és menor que 0)
    • "Zero" (si és igual a 0)

    ℹ️ Aquest exercici es prova automàticament amb tres valors: 15, -4 i 0.

    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Número: ");
        int num = sc.nextInt();

        if (num > 0) {
            System.out.println("Positiu");
        } else if (num < 0) {
            System.out.println("Negatiu");
        } else {
            System.out.println("Zero");
        }
    }
}

    💻 Exercici Pràctic RA5 (2 punts)

    ☕ Repte Bàsic: Entrada amb Scanner i Càlcul d'Edat

    Valor: 2.0 punts
    Enunciat: Fes un programa que demane per teclat el nom de l’usuari i la seua edat.
    Després, el programa ha de calcular l'any de naixement (suposant que estem en 2026) i mostrar el missatge exacte:
    "Hola <nom>, vas nàixer l’any <any>."
    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nom: ");
        String nom = sc.nextLine();

        System.out.print("Edat: ");
        int edat = sc.nextInt();

        int anyNaixement = 2026 - edat;

        System.out.println("Hola " + nom + ", vas nàixer l'any " + anyNaixement + ".");
    }
}

    💻 Exercici Pràctic RA6 (2 punts)

    ☕ Repte: Recorregut d'un vector i cerca de Màxim i Mínim

    Valor: 2.0 punts
    Enunciat: Fes un programa que:
    • Cree un vector d'enters de mida 5 (new int[5]).
    • Demane cada número per teclat amb un bucle for.
    • Calcule i mostre el valor màxim i el mínim trobats al vector.
    Consola de Sortida Java
    💡 Solució de referència comentada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int[] numeros = new int[5];

        for (int i = 0; i < 5; i++) {
            System.out.print("Número " + (i + 1) + ": ");
            numeros[i] = sc.nextInt();
        }

        int max = numeros[0];
        int min = numeros[0];

        for (int i = 1; i < 5; i++) {
            if (numeros[i] > max) {
                max = numeros[i];
            }
            if (numeros[i] < min) {
                min = numeros[i];
            }
        }

        System.out.println("Màxim: " + max);
        System.out.println("Mínim: " + min);
    }
}

    🧪 Exercici integrat 1 — Anàlisi de temperatures

    🌡️ Repte integrat: temperatures màxima, mínima i dies calorosos

    Pràctica · 1.0 punt
    Enunciat: llegeix 5 temperatures, guarda-les en un vector i mostra la màxima, la mínima i quantes són superiors a 30. Completa els TODO:
    • RA1: afegeix un comentari // i declara la variable calorosos.
    • RA6: recorre el vector per trobar max i min.
    • RA3: compta els valors > 30 amb un if.
    • RA5: mostra les tres dades amb System.out.println.
    Consola de Sortida Java
    💡 Solució guiada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Llegeix temperatures i calcula la màxima, la mínima i els dies calorosos
        Scanner sc = new Scanner(System.in);
        int[] temps = new int[5];

        for (int i = 0; i < 5; i++) {
            System.out.print("Temperatura " + (i + 1) + ": ");
            temps[i] = sc.nextInt();
        }

        int max = temps[0];
        int min = temps[0];
        int calorosos = 0;

        for (int i = 1; i < 5; i++) {
            if (temps[i] > max) { max = temps[i]; }
            if (temps[i] < min) { min = temps[i]; }
            if (temps[i] > 30) { calorosos++; }
        }

        System.out.println("Màxima: " + max);
        System.out.println("Mínima: " + min);
        System.out.println("Dies calorosos: " + calorosos);
    }
}

    🧪 Exercici integrat 2 — Notes i mitjana

    🎓 Repte integrat: mitjana i recompte d'aprovats

    Pràctica · 1.0 punt
    Enunciat: llegeix 4 notes, guarda-les en un vector, calcula la mitjana sencera i compte quantes són majors o iguals que 5. Completa els TODO de RA1 (comentari i variables), RA5 (entrada i sortida), RA6 (vector) i RA3 (bucle i if).
    Consola de Sortida Java
    💡 Solució guiada: 
    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        // Llegeix notes, calcula la mitjana i compta els aprovats
        Scanner sc = new Scanner(System.in);
        int[] notes = new int[4];
        int suma = 0;
        int aprovats = 0;

        for (int i = 0; i < 4; i++) {
            System.out.print("Nota " + (i + 1) + ": ");
            notes[i] = sc.nextInt();
            suma = suma + notes[i];
        }

        for (int i = 0; i < 4; i++) {
            if (notes[i] >= 5) {
                aprovats++;
            }
        }

        int mitjana = suma / 4;

        System.out.println("Mitjana: " + mitjana);
        System.out.println("Aprovats: " + aprovats);
    }
}
